# BlockChain-Based-Secure-Platform
The Blockchain-Based Secure Platform is a web application designed to manage digital identities, control user access, and secure digital assets. It uses SHA-256 hashing, role-based access control, and a simulated audit ledger to track activities. Users can register assets, grant or revoke permissions, and transfer ownership securely.
# Blockchain-Based Secure Platform for Identity, Access Control, and Digital Asset Management

## 📌 Project Overview
This project is a web-based application designed to demonstrate secure digital identity management, role-based access control, and digital asset management using blockchain-inspired concepts.

## 🚀 Features
- Digital identity registration and management.
- SHA-256 hashing for identity verification.
- Role-Based Access Control (USER, AUDITOR, ADMIN).
- Digital asset registration and management.
- Grant and revoke asset access permissions.
- Transfer digital asset ownership.
- Transaction history and audit logging.
- Dashboard with platform statistics.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Web Crypto API (SHA-256)
- Browser LocalStorage

## ▶️ How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Connect the simulated wallet.
5. Explore identity, access control, and asset management features.

## 🔐 Security Features
- SHA-256 hashing for identity data.
- Role-based permissions.
- Asset access management.
- Transaction history with timestamps and hashes.

## ⚠️ Disclaimer
This project is an educational prototype. Wallet connections, blockchain transactions, and audit records are simulated. It is not connected to a real blockchain network.
